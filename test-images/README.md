# AVA — test images for the jury

Download all five: **[AVA_test_images.zip](https://github.com/TheRizaev/AVA-Product/raw/main/test-images/AVA_test_images.zip)**
Then open the live site **https://therizaev-ava-check.hf.space** and upload them with the **Gallery** button.

## Surface check (1 photo)
| File | What it is | Expected |
|---|---|---|
| `surface_1_seat_leather_NO_DEFECT.jpg` | seat leather, no defect (real photo) | **PASS** |
| `surface_2_car_door_SCRATCH.jpg` | car door with a thin scratch (real photo, cropped) | **FAIL**, zones on the scratch |
