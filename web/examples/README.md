# Built-in demo examples

The five images behind the "Try an example" buttons of the AVA web UI. The buttons only load
these files into the photo slots (exactly like picking them from the gallery); the verdict is
always computed by the real API (`/api/scan`, `/api/compare`). Nothing is hard-coded.

| File | Mode | Content | Expected result |
|---|---|---|---|
| `surface_defect.jpg` | Surface check | orange car paint with a bright scratch and a paint chip | FAIL, zone on the defect |
| `surface_ok.jpg` | Surface check | the same paint without the defect | PASS, no zones |
| `compare_reference.jpg` | Compare with reference | golden part: stamped steel plate (holes, slot, ribs, bend) on a mat | (reference) |
| `compare_defect.jpg` | Compare with reference | the same part with masking tape on it, small camera jitter | FAIL, zone on the tape |
| `compare_light.jpg` | Compare with reference | the same part, no defect, strong global lighting change (gamma 1.3, exposure x0.65, warm cast), small camera jitter | AVA PASS; plain reference subtraction: false FAIL (whole frame changed) |

## Source and licence

**Synthetic.** All five are generated by [`eval/make_examples.py`](../../eval/make_examples.py)
from the procedural renderer in `dalil/synth.py` (no external images, no people, no faces, no
licence plates). They are part of this repository and share its licence. Regenerate with:

```
python -m eval.make_examples            # prints the chosen seeds and scores
```

The script searches a small fixed list of seeds and writes the first candidate whose verdicts
from the real pipeline clear the thresholds with a wide margin (see `MARGIN` / `CLEAN_MARGIN`
in the script), so the examples keep working after a small re-calibration.

## Replacing them with real photos

The team may replace any of these files with its own photos **under the same file names**
(JPEG; no people or licence plates in the frame). Afterwards run

```
python -m pytest -q tests/test_demo_examples.py
```

which runs the real pipeline on the five files and checks the four expected verdicts. Do not
deploy if it fails.
